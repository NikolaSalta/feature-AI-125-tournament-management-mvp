# QA Team Documentation

Эта папка содержит всю тестовую документацию для проекта Tournament Service Backend.

## Структура папок

```
qa-team/
├── AI-132-initialize-backend/    # Тестирование инициализации проекта
│   ├── test-docs/               # Документация по тестированию
│   ├── test-evidence/           # Скриншоты и логи
│   └── test-scripts/            # Автоматизированные скрипты
├── AI-133-tournament-domain/     # (будущее) Тестирование доменной модели
└── README.md                     # Этот файл
```

## Соглашения по именованию

- Папки тикетов: `{TICKET-ID}-{short-description}/`
- Тестовые отчеты: `TEST_REPORT_{TICKET-ID}_{DATE}.md`
- Скриншоты: `{test-case-id}_{description}.png`
- Логи: `{test-case-id}_{description}.log`

## Процесс тестирования

1. Создать папку для тикета
2. Скопировать тестовую документацию
3. Выполнить тесты согласно документации
4. Собрать evidence (скриншоты, логи)
5. Создать финальный отчет
6. Закоммитить результаты
